# Deep Learning Projects

Curated deep-learning code from sequence modeling and final-project experiments.

## What It Demonstrates

- RNN and LSTM implementations.
- Encoder-decoder sequence-to-sequence modeling.
- Transformer model components.
- Machine-translation utilities.
- Fine-tuning and context-distillation experiment scripts.

## Structure

- `machine_translation/`: Transformer, RNN/LSTM, Seq2Seq, utilities, environment files, and architecture image.
- `final_project/`: fine-tuning and distillation scripts.

## Public-Safe Scope

This repository excludes datasets, model checkpoints, notebooks with embedded outputs, assignment PDFs, and submission archives.
